## 👋 Sobre mí

Soy **Leo**, desarrollador web de Colombia apasionado por crear experiencias digitales limpias y con propósito. Me muevo cómodo entre frontend y backend, y disfruto tanto el diseño como la lógica detrás de cada proyecto.

- 🔭 Trabajando en proyectos con **React, Next.js y Tailwind CSS**
- ⚡ Explorando **Astro** para sitios rápidos y modernos
- 🌱 Aprendiendo **TypeScript** y buenas prácticas de **UI/UX**
- 🎮 Prototipando ideas con **Godot** en mis tiempos libres
